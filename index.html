Core Capabilities

Automated Code Quality Metrics

Engineered to give engineering students immediate diagnostic feedback on their Java lab exercises and semester assignments.

📊

Structural Metrics

Instantly counts Lines of Code (LOC), number of classes, declared methods, class fields/variables, loop structures, and conditionals.

🧠

Cyclomatic Complexity

Calculates McCabe's Cyclomatic Complexity through control-flow branching points (if, for, while, case, boolean operators).

🧱

Stack-Based Nesting Depth

Utilizes bracket-matching Stack data structures to compute maximum indentation and scope nesting levels, flagging deeply nested logic.

⚠️

Intelligent Issue Detection

Detects poor naming conventions, bloated methods exceeding 30 lines, missing Javadoc comments, and lines surpassing 100 characters.

🎯

0 to 100 Quality Score

Generates a comprehensive quality score balanced across complexity, readability, and maintainability with transparent deduction penalties.

📋

Submission History & Reports

Saves all analyzed reports linked to student profiles in MySQL via JDBC PreparedStatement queries for continuous academic evaluation.

Student Workflow

How CodeMetrics Operates

A clear, 4-step pipeline that transforms raw Java source code into structured quality insights.

1

Submit Java Code

Paste Java source code into the clean editor interface or choose from pre-built test cases (good design, long method, or deep nesting).

2

Lexical Tokenization

The Java string analyzer parses tokens, skips comments and blank lines, and populates HashMaps for identifier frequency tracking.

3

Heuristic & Rule Evaluation

Analyzers inspect method boundaries, measure nesting depth using stacks, count loops, and classify issues by severity (HIGH, MEDIUM, LOW).

4

Interactive Quality Report

Review the overall score gauge, subscores, issue cards with line numbers and suggestions, and highlighted source code inspection view.

Academic Design

System Architecture & DFD

Strictly conforms to standard B.Tech CSE requirements: HTML/CSS/JS frontend, Java application backend, JDBC connectivity, and MySQL database.

HTML5 / CSS3 / Vanilla JS → Java Backend (DAO / Analyzer) → JDBC API → MySQL Database

📌 DFD Level 0 (Context Level)

  • External Entity: Student / Evaluator
  • Input: User Credentials, Java Source Code, Submission Title
  • Central Process: CodeMetrics System (0.0)
  • Output: Code Quality Report, 10 Metrics, Severity-ranked Issues, Improvement Suggestions

⚙️ DFD Level 1 (Major Processes)

  • 1.0 User Management: Register, Login, Session Verification
  • 2.0 Code Submission: Capture and validate Java code text
  • 3.0 Code Analysis: Parse tokens, measure metrics, detect issues
  • 4.0 Report Generation: Compute 0-100 quality score and breakdown
  • 5.0 Submission History: Retrieve past student submissions

🗄️ Data Stores (MySQL Tables)

  • D1 – USERS: user_id, name, email, password, created_at
  • D2 – SUBMISSIONS: submission_id, user_id, title, code, score
  • D3 – ANALYSIS_RESULT: loc, classes, methods, complexity, readability
  • D4 – CODE_ISSUES: severity, line_number, issue_type, message, suggestion
Academic Overview

About CodeMetrics

CodeMetrics is developed as a B.Tech Computer Science and Engineering semester project. It bridges the gap between theoretical software engineering principles (such as cohesion, coupling, cyclomatic complexity, and code smells) and practical student lab coding. By providing instant, non-judgmental automated code critiques, students learn to write clean, maintainable, and robust Java applications.

Project Scope & Mark Allocation (Phase 1 / 50 Marks):

  • Complete 7-page responsive HTML5/CSS3/Vanilla JS UI layout (No external heavy frameworks).
  • Full Java Backend architectural design with DAOs, Models, and Analyzers.
  • MySQL Schema Definition (schema.sql) with normalized tables and relational constraints.
  • Interactive Java code analyzer with test presets and comprehensive report generation.
  • System documentation featuring DFD Level 0, Level 1, Level 2, and viva preparation guide.
